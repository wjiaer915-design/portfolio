The Sleep Wave Project

小宇宙世界睡眠日
H5 营销活动全案

以“睡眠焦虑”和“夜间情绪陪伴”为切入点，围绕小宇宙播客平台构建世界睡眠日 H5 活动方案。 项目通过沉浸式 3D 睡眠舱视觉、入睡测试、盲盒歌单推荐与签到奖励机制， 将助眠内容从单向收听转化为可参与、可分享、可留存的品牌互动体验。

Role

Visual Design / H5 Campaign / AIGC Direction

Type

Marketing Campaign / Interactive H5

Tools

AIGC / Photoshop / Figma

Year

2026

01

Project Introduction

随着睡眠焦虑与夜间情绪需求上升，用户对助眠播客的使用逐渐从“听内容”转向“被陪伴”。 但在现实体验中，助眠内容常面临入口分散、选择成本高、复访动力弱等问题。 本项目以“小宇宙世界睡眠日”为主题，尝试通过 H5 活动将平台中的助眠内容重新组织， 形成更具沉浸感、游戏感与情绪安抚价值的运营方案。

设计以“宇宙睡眠舱”为核心视觉隐喻，将助眠过程转译为一次轻量化的太空旅行体验。 用户可以通过入睡频段测试、疗愈盲盒歌单、听觉陪伴任务和签到奖励机制， 逐步完成从内容发现到持续收听的行为转化。

02

Design Objectives

刺激夜间收听与内容转化

通过沉浸式睡眠舱 KV 与入睡频段测试，降低用户选择成本， 将内容入口从被动浏览转化为主动参与。

提升平台粘性与复访率

以签到、奖励和连续收听任务增强活动节奏， 让助眠内容从一次性体验变成可持续的夜间习惯。

构建助眠内容生态

将节目单、盲盒推荐和用户分享路径整合为稳定入口， 形成“平台—内容—用户”的循环增长。

强化品牌陪伴感

以温柔、治愈、轻盈的视觉语言塑造小宇宙在夜间场景中的情绪价值， 强化品牌记忆点。

03

Target Users

活动面向 18–35 岁都市年轻群体、睡眠困扰与情绪调节人群、播客及白噪音内容爱好者， 以及高压学习与办公人群。此类用户通常拥有较强的夜间内容消费需求， 但也容易受到信息过载、选择困难和持续动力不足的影响。

因此，项目并不只解决“推荐什么内容”的问题，而是进一步思考： 如何让用户在夜晚愿意打开、愿意停留、愿意分享，并在平台中建立稳定的助眠使用习惯。

04

Design Strategy

核心定位

将助眠内容包装为“沉浸式太空旅行体验”，弱化工具感，强化陪伴感与仪式感。

视觉主题

围绕睡眠舱、星空、云朵、电波、收音机等元素，构建柔和、梦幻、具有记忆点的视觉系统。

情绪基调

以温柔、治愈、轻盈为主要情绪方向，避免高压促销感，让用户进入更松弛的夜间状态。

页面流程

通过“引导—测试—推荐—打卡—奖励—分享”的路径，提高活动完成度与复访率。

05

Visual System

视觉上采用深空蓝、紫色渐变与柔和暖光作为主色调，形成夜晚、梦境与宇宙感的联想。 主视觉中的睡眠舱兼具收音机、播客与太空舱的形态特征，使平台属性与睡眠主题自然结合。

AIGC 在本项目中主要承担视觉概念生成与氛围探索的作用，帮助快速形成具有场景感的主视觉方向； 后续再通过人工调整完成版式节奏、品牌信息、活动入口与页面系统的统一。

06

Outcome

最终方案形成了一套从活动主视觉、项目介绍、目标用户分析到设计策略拆解的完整展示系统。 项目不仅呈现了 AIGC 在运营视觉中的辅助价值，也进一步探索了播客平台如何通过节日节点、 情绪场景和互动机制，将内容消费转化为更具参与感的品牌体验。
